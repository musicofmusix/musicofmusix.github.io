# Features
- Fully real-time rendering
- An anime-style visual aesthetic with toon shading
- Rigged 3D character created in [VRoid Studio](https://vroid.com/en/studio) and ported to Unity
- Dynamic text and text effects that respond to user interaction

<img src="/assets/img/sairi/glitchtext_demo.gif" class="w-full h-auto mx-auto">

- A customisable polka-dot effect for backgrounds, implemented in URP Shadergraph

<img src="/assets/img/sairi/polkadots_demo.webp" class="w-full h-auto mx-auto">

- Procedurally generated Bezier spline curves and particles (The core logic of this process is also implemented in Python: [bezierspline](https://github.com/musicofmusix/bezierspline))

<img src="/assets/img/sairi/pinkline_demo.gif" class="w-full h-auto mx-auto">

- Real-time depth-based shader replacement for special masking effects

<img src="/assets/img/sairi/curtain_demo.gif" class="w-full h-auto mx-auto">

- Animated transitions for all interactive and non-interactive objects on screen
- Character eye-tracking and natural blinking

# Installation
- The project was developed and tested on Unity version 2021.3.9f1 LTS. Simply clone the [GitHub repository](https://github.com/musicofmusix/sairi) and open it in the editor. Newer versions of the Unity editor were not tested, but will likely work.
- After opening the project, the [URP-UniVrm](https://github.com/EvelynGameDev/URP-UniVrm) [.unitypackage](https://github.com/EvelynGameDev/URP-UniVrm/releases) must be imported into the project for proper character rendering. The version used during development was 1.0.4.
- Builds have been tested on macOS, Windows 11, iOS, and WebGL 2.
